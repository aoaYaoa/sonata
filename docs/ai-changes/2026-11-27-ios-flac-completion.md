# 2026-11-27 · iOS 在线 FLAC 播放结束

## 原因与修复

iPhone 用网易云《海屿你》复现了播到尾声后停住的情况。AVPlayer 的原生播放时钟超过了 295.96 秒的曲长，始终未发送播放结束通知，自动切歌因此没有启动。iOS 加载带 `.flac` 扩展名的 HTTP 音源后，使用已知时长设置原生播放终点。

自动切歌时，控制器内部的暂停会暂时让引擎报 `playing: false`。媒体服务在交接中继续保持播放状态，换源产生的 `idle` 仍映射为 `loading`。媒体控制中的显式暂停和停止会退出交接状态。

## 验证

- `flutter test --no-pub --reporter expanded` 通过 31 项测试，新增覆盖 FLAC 播放终点和交接内部暂停。`dart analyze lib test` 无问题。
- iPhone 14 Pro Max 用同一队列的线上无损源验证，从《海屿你》最后 8 秒自然播放到结尾，自动切到《我不难过》。下一首命中预取，切换期间媒体服务未收到 `idle`。随后将第二首拉到尾段，也收到原生播放结束事件。
